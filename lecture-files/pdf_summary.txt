Prof. Mehdi Pirahandeh
1 Introduction to CPU Scheduling
In operating systems, CPU scheduling determines which processes in the ready queue are
allocated to the CPU for execution. Scheduling aims to ensure efficient CPU utilization
and minimize waiting times. Several algorithms exist, each with different benefits and
drawbacks.
2 Basic Concepts
• Multiprogramming: A technique that aims to maximize CPU utilization by
allowing multiple processes to be executed simultaneously.
• CPU–I/O Burst Cycle: Processes alternate between CPU execution and I/O
wait. Efficient scheduling requires an understanding of CPU burst distribution,
which consists of many short bursts and fewer long ones.
